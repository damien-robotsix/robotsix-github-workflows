`pin-bump-sweep.yml` is `workflow_call`-only again. Its `schedule` and `workflow_dispatch` triggers fired inside this repository, which holds no `RELEASE_APP_ID`/`RELEASE_APP_PRIVATE_KEY` of its own, so every such run would die at token minting. The weekly schedule belongs in a caller stub that owns the credentials — as the README's caller template already showed — and the `vars.PIN_BUMP_APP_ID` / `secrets.PIN_BUMP_APP_PRIVATE_KEY` fallbacks are dropped with them.
